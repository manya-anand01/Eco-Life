🌱 EcoLife — Sustainable Living Website

EcoLife is a frontend website built to nudge people toward simple, sustainable habits. It's a clean, structured webpage built with HTML5 and CSS3.

🌍 About the Project

EcoLife walks users through sustainable living, eco-friendly habits, environmental challenges, and eco-friendly products. I built it as a frontend practice project to get more comfortable with HTML and CSS.

✨ Features

- Responsive navigation structure
- Hero section with call-to-action
- About EcoLife section
- Eco-friendly tips
- Eco-friendly products table
- 7-Day Green Challenge
- User registration form
- Footer with navigation links
- Semantic HTML structure

🛠️ Technologies Used

- HTML5
- CSS3

📂 Project Structure

EcoLife/

├── index.html

🎯 Learning Objectives

This project gave me hands-on practice with semantic HTML, forms, tables, lists, and navigation links, plus buttons and input elements. On the CSS side, I worked through selectors, layouts, component styling, and general site structure and organization.

🚧 Current Limitations

Right now this is frontend-only. The registration form has no backend, so submitted info doesn't get stored anywhere. There's also no JavaScript-based interactivity yet, and no real authentication.

🚀 Future Improvements

A few things I'd like to add down the line:

- JavaScript interactions
- User authentication
- Backend integration
- Database storage
- Functional challenge tracking
- Product purchasing functionality
- User dashboard
- Sustainability progress tracking
- AI-powered personalized eco recommendations

📌 Project Status

Frontend prototype — HTML & CSS. This is a learning project, not a production-ready app.
